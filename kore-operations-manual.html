Two Rules Used Throughout

One carton = 24 pairs. Every quantity in the portal is counted in cartons, and each carton holds a fixed set of sizes that always totals 24 pairs.

Carton SKU. Every colour and size-range combination has one Carton SKU. The portal creates the SKU for each individual size from it. SKUs are what is scanned during goods receipt, so they must be accurate and unique.

Catalogue — Method 1: Add a Master Article

Creating one article manually, with all its colours and sizes

Inventory → Catalogue → Add New Master
📘

What is a Master Article?

A Master Article is one product (for example “Urban Runner”). It contains variants: one for every colour and size range. Stock, price and images are managed at variant level.

Step 1 — Core Information

FieldStatusWhat to enter
Article NameRequiredThe product name. The first letter is capitalised automatically.
Sole ColorOptionalColour of the sole.
MRP (₹)RequiredMaximum retail price per pair.
Gender AudienceRequiredMen, Women or Kids.

Step 2 — Colours and Size Ranges

1
Add coloursType a colour and press Enter or select Add. Repeat for every colour.
2
Add size rangesType a range such as 5-7 and press Enter. Kids ranges may cross over, for example 11-03.
3
Review the variant listThe portal creates one row for every colour and size-range combination.

Step 3 — Category and Manufacturing

FieldStatusWhat to enter
CategoryRequiredSelect from the list. A new category can be added from the same box.
BrandRequiredBrands are shown for the selected category, so choose the category first. A new brand can be added from the same box.
ManufacturerRequiredSelect or add.
Base UnitRequiredSelect or add (for example, Pair).

Step 4 — Listing Status

Active / Available: the article appears in the distributor catalogue and can be ordered once stock exists.
Coming Soon (Pre-Order): the article is shown as “Available in 30 Days” and can be pre-booked. An Expected Availability date is required.

Catalogue — Variant Details and Images

Completing each colour before saving

Step 5 — Fill in the Variant Table

Each colour has its own section. For every row (colour + size range), complete the following:

FieldStatusWhat to enter
Item Variation NameOptionalFilled in automatically. It may be edited.
Carton SKURequiredUnique code for this colour and size range, for example ECH-BLK-M-5-8.
Cost Price (₹)OptionalPurchase cost per pair.
MRP (₹)OptionalVariant-level MRP per pair.
HSN CodeOptionalTax classification code.
Size quantitiesRequiredPairs of each size inside one carton. The total must be 24 (or a multiple of 24). The row shows “Must be ÷24” if it is not.
⚡

Time-savers

Use Copy All under Cost Price or MRP to apply one value to every row of the colour. Use Apply for HSN code and for a size quantity to copy it to the other rows.

Step 6 — Add Images

1
Locate “Media for [colour]”Every colour has its own image area.
2
Select Add ImagesChoose one or more image files from your computer. Several can be chosen at once.
3
Choose the cover imageThe first image is the cover shown in the catalogue. To change it, select Set as cover on another image or drag the images into the order required.
4
Remove an image if neededUse the remove icon on the image.
🖼️

Image guidance

Use clear product photographs, one set per colour. Images are compressed automatically when saved, so very large files do not need to be resized first.

Step 7 — Save

Select the save button at the bottom of the form. The portal checks the form before saving. Typical messages and their meaning:

MessageAction
Please fill all required fieldsComplete the article name, category, brand, manufacturer and unit.
Total quantity must be a multiple of 24Correct the size quantities of the variant named in the message.
Carton SKU is requiredEnter the Carton SKU for the variant named in the message.

Catalogue — Method 2: Spreadsheet Import

Creating many articles at once from a spreadsheet file

Inventory → Catalogue → Import CSV
1
Prepare the spreadsheetUse Excel. Enter the column names exactly as listed below in the first row, and one row per colour and size range.
2
Save as CSVIn Excel choose File → Save As → CSV (Comma delimited).
3
Open the import windowSelect Import CSV. Select Download Sample CSV to see the correct layout.
4
Upload the fileChoose the CSV file, or paste its text into the box, then select Parse & Continue.
5
Review the previewThe portal lists every article found and highlights any conflicts. For each conflict, choose to import or skip.
6
ImportConfirm. The portal reports how many items were imported or skipped.

Columns Required in Every File

ColumnStatusWhat to enter
nameRequiredArticle name. Rows with the same name become one article with several colours.
colorRequiredColour of the variant.
skuRequiredCarton SKU, for example ECH-BLK-M-5-8. The SKU for each size is created from it.
sizeRequiredSize range, for example 5-8.
tagRequiredonline or offline.
genderRequiredMEN, WOMEN or KIDS.
listing_statusRequiredavailable or wishlist (pre-order).
size_5, size_6 …RequiredOne column per size. Enter the pairs of that size in one carton. The row must total 24.

Columns That May Be Left Out

ColumnStatusWhat to enter
online_mrp / offline_mrpOptionalMRP per pair. Fill the one that matches the row’s tag; otherwise the MRP is zero.
cost_price, hsnOptionalCost per pair and HSN code.
category, brand, manufacturer, unitOptionalRecommended for new articles. Any that do not exist are created automatically.
imageOptionalWeb link to the colour’s image. One image per colour.
sole_colorOptionalSole colour.
expected_dateOptionalExpected availability date for wishlist rows. Formats such as 01/07/2026 or 2026-07-01 are accepted.
⚠️

Please note

Importing creates the articles with zero stock. Stock is added later through GRN. Variants that already exist (same colour, size range and carton set) are skipped, not duplicated. For kids sizes that cross over, use columns size_11, size_12, size_13, size_01, size_02, size_03 with the range 11-03.

Catalogue — Method 3: Edit an Existing Article

Adding colours, sizes or images to an article that already exists

Inventory → Catalogue → open the article → Edit
1
Find the articleUse the search box (article name or SKU), the gender buttons or the sort list. Use the Available Catalogue or Pre-Order tab.
2
Expand the article and select EditThe same form opens with the existing details filled in.
3
Add a colourType the new colour in Product Colors and press Enter. New rows appear for the new colour.
4
Add a size rangeType the range and press Enter. To add a range for one colour only, use the box inside that colour’s section.
5
Complete the new rowsEnter the Carton SKU and size quantities exactly as in Method 1.
6
Add or change imagesUse Add Images inside the colour’s section. Existing images can be removed or re-ordered.
7
SaveThe new variants are added without affecting existing ones.

Other Catalogue Actions

ActionHow
View a variantSelect the variant to open its details page: SKUs, images and live stock by size.
Move a Pre-Order article to AvailableEdit the article and change the Listing Status. An article can move from Pre-Order to Available, but not back.
Delete an articleUse the delete option on the article and confirm.
✅

Checklist before moving on

Every colour has a Carton SKU on each size range · every row totals 24 pairs · each colour has a cover image · the listing status is correct.

Master Stock

Viewing, adding and removing stock, and keeping it tallied

Inventory → Master Stock

Master Stock shows the physical stock of every article in cartons. It has two tabs.

TabPurposeCards at the top
RFDReal stock that is in the warehouse and can be sold.Available · Booked (reserved for orders) · PO Pending (ordered, not yet received)
Pre-OrderPlanned quantities for articles that have not yet arrived.Total · Planned (a PO has been raised) · Booked (reserved by distributors)

Use the search box to find an article. Expand it to see each variant with its cartons. The Alert box sets the low-stock level in cartons; articles below it are marked Low Stock.

Recording a Manual Stock Movement

1
Select Stock MovementChoose Inward (add stock) or Outward (remove stock).
2
Choose the article and variantSearch the article, then select the colour and size range.
3
Enter cartons and reasonInward reasons: Purchase / GRN, Returned Stock, Stock Transfer In, Manual Correction, Other. Outward reasons: Damage / Defect, Sample Issue, Lost / Missing, Stock Transfer Out, Manual Correction, Other. Add a note if helpful.
4
Review and confirmCheck the “After Movement” quantity, then confirm. For an inward of physical cartons, the portal produces carton labels to print and stick on each carton.
📌

Pre-Order tab

An inward recorded on the Pre-Order tab is a planned quantity only. It is not sellable until goods are received through a GRN.

Keeping Stock Tallied

A simple routine to make sure the portal matches the warehouse

The portal updates stock automatically from GRN, dispatch and returns. To confirm that the system and the warehouse agree, carry out the following check regularly.

1
Count the cartonsCount the physical cartons of a colour or article in the warehouse.
2
Compare with the portalOpen Master Stock → RFD and compare with the Available figure. Remember that Booked cartons are reserved for orders that have not yet been dispatched.
3
Find the cause of any differenceCheck the Stock Report, recent GRNs, dispatches and returns for the article, and the Activity Log for manual changes.
4
Correct the differenceRecord a Stock Movement for the difference with the reason Manual Correction (or Damage / Defect, Lost / Missing as appropriate) and add a note.
5
ConfirmThe “After Movement” figure should now equal the physical count.
🔍

Good practice

Always enter a note with a manual correction. Every stock movement is recorded in the Activity Log with the user and time, so differences can be explained later. Avoid correcting stock by any other means.

Purchase Orders

Ordering goods from a vendor and getting the order approved

Purchases → PO → Create PO
1
Select the vendorSearch and select. The vendor’s billing and shipping addresses appear below.
2
Complete the headerReference# (optional), Date, Delivery Date, Payment Terms and Shipment Preference. The Purchase Order# is assigned automatically when the PO is approved.
3
Add itemsSelect Select Items, search, tick the required variants and select Done. Pre-Order items carry a “Pre-Order” label.
4
Enter quantitiesOpen the quantity grid for an item. Enter the size quantities for one carton (they must total 24), confirm the SKU for each size, and set the number of cartons.
5
Check prices and taxEnter or confirm the MRP per pair, cost per pair, HSN code and GST %. Line totals and the order totals are calculated automatically.
6
Add a discount, notes and termsOptional. Notes and Terms & Conditions are printed on the PO.
7
SaveSave as Draft keeps it for later editing. Save and Send submits it for approval.

Approval

1
Open the billAccounts → Bills. A PO that has been sent appears here with the status Pending.
2
ReviewCheck vendor, items, quantities, prices and totals. The bill can be downloaded as PDF or Excel.
3
Approve or rejectChoose the action and enter the remarks. Approval allocates the PO number.
🔒

After approval

An approved PO can no longer be edited. A rejected PO returns to the PO list with the remark; correct it and send it again. It will then be marked Revised.

The PO list shows the PO Status, Bill Status and Approval Remark for every order. A PO can be searched by number or vendor and downloaded as PDF.

Goods Receipt Note (GRN)

Receiving goods against an approved purchase order

Purchases → GRN → Create GRN
1
Select the Purchase OrderSearch and select the PO. Its summary — vendor, dates, quantity and items — is displayed. If one shipment covers more than one PO, use Link another PO.
2
Fill in the receipt detailsGRN Date, Received By, Mobile No and Warehouse / Location are required.
3
Add document referencesOptional: invoice numbers, challan numbers (type each and press Enter), e-way bill number, vehicle number and remarks.
4
Choose an itemSelect an item in the left panel. Its cartons are shown as numbered chips.
5
Scan each cartonScan or type the size SKU and press Enter. Each scan adds one pair. A size cannot exceed its quantity in the carton. A carton is complete at 24 pairs.
6
Confirm the carton labelWhen a carton reaches 24 pairs, scan its printed carton label to confirm it. The chip turns green.
7
Repeat for all cartons and itemsThe progress bar shows the cartons completed.
8
Submit GRNThe button is available when the receipt details are complete and every started carton is full and confirmed.

Chip Colours

ColourMeaning
BlueCarton currently being scanned
AmberPartly scanned
OrangeFully scanned, waiting for the label to be confirmed
GreenCarton confirmed
✅

Result

When the GRN is submitted, the cartons are added to Master Stock and become available for sale. A carton that has already been received cannot be received again. If a carton was scanned wrongly, use Reset carton before submitting.

The History tab lists every GRN. It can be filtered by PO reference, opened for detail and exported to Excel.

Distributor Orders and Dispatch

From the moment an order is placed until it is delivered

Sales → Orders

The Orders page shows summary cards (Total CTN, Pending, Dispatched, In Transit, Delivered). Select a card to filter the list, and open an order to work on it.

1
Book the orderOpen a Pending order and select Book Order. Optionally enter the expected dispatch date, a priority and an internal note. The order moves to Booked.
2
Scan cartonsOpen the Scan Cartons tab. Scan each carton’s code as it is packed. Stock reduces as cartons are scanned for dispatch.
3
Enter transport detailsIn the transport tab, select the scanned cartons and enter the Vehicle No and Transporter Name (required). Optionally add the LR number, e-way bill number, driver name and mobile, gross weight and the Tax Invoice, E-Way Bill and Transport Bill documents. Submit to mark the cartons In Transit.
4
Confirm receiptWhen the goods arrive, open Confirm Receipt, select the cartons and enter the Receiver Name and Mobile Number. A receiving note may be attached. The cartons are marked Delivered.
📦

Partial dispatch

An order can be dispatched in batches. Each batch has its own transport details, invoice and receipt, and the order shows Partial Delivered until all cartons are delivered.

Pre-Orders and Cancellation

Pre-orders appear as Pre-Booked and are then Confirmed. Orders may be edited while Pending or Pre-Booked and cancelled until they are dispatched.

Documents

From an order, a Proforma Invoice can be downloaded as PDF or Excel. Uploaded documents can be previewed by selecting them.
